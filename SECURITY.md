# Security Policy

## Reporting a Vulnerability

We take the security of PharosPay seriously. If you find a security vulnerability, please do not report it publicly through GitHub issues. Instead, report it privately.

Please send vulnerability details to the project maintainers via email at:
`security@pharospay.io`

Include as much details as possible to help us reproduce the issue:
* Detailed steps to reproduce the vulnerability.
* A proof of concept (PoC) script or execution steps.
* Potential impact of the issue.

We will review your submission and respond within 48 hours to coordinate a disclosure and patch timeline.
